# Meus clientes (offline)

App offline de clientes. Os dados ficam só no aparelho.

## Baixar o APK
1. Aba **Actions** do repositório → workflow **Gerar APK** → execução mais recente.
2. Em **Artifacts**, baixe `meus-clientes-apk` (zip), extraia e instale o `app-debug.apk`.
   (No Android, permita "instalar apps de fontes desconhecidas".)

Para gerar de novo: Actions → Gerar APK → **Run workflow**.

## Avisos
- Desinstalar o app apaga os dados: faça backup antes.
- "Baixar backup", "Exportar planilha" e "Abrir WhatsApp" podem precisar de ajuste dentro do APK.
